# TapeExit Logo

标志将 Exit 的字母 E 与出口箭头合为一个连续图形。上下横线呼应 Tape 的带状结构，中间箭头表达始终保留的退出路径。

| 文件 | 用途 |
| --- | --- |
| `tapeexit-logo.svg` | 可缩放的矢量图标 |
| `tapeexit-wordmark.svg` | 图标与名称的横向组合 |
| `tapeexit-wordmark.png` | README 等场景使用的透明底组合标志 |
| `tapeexit-wordmark-dark.png` | 深色背景使用的白色组合标志 |
| `../../public/tapeexit-icon.png` | 应用侧栏及浏览器图标 |

主色为 `#2A6448`，文字色为 `#26342C`。标志四周至少保留主图形宽度的六分之一作为留白；保持宽高比例，不添加阴影或渐变。小尺寸优先使用纯图标。

SVG 可直接编辑、无损缩放；PNG 用于需要位图的展示场景。
