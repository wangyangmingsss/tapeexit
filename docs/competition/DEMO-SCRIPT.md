# TapeExit 演示脚本

视频不超过 3 分钟，使用中文合成旁白并明确标记场景。
模拟操作取自[在线 Demo](https://wangyangmingsss.github.io/tapeexit/)对应源码的 CI 录像，
真实结果取自固定版本公网验收截图与链上报告；视频元数据分别记录两个源码提交。
精确时长和逐场旁白见交付包 `video.json`，不能将画面理解为钱包签名直播。

| 时间 | 画面与操作 | 讲解要点 |
| --- | --- | --- |
| 0:00–0:20 | 已发布公网界面与产品问题 | TapeExit 是基于 TapeOut 的 X Layer DeFi 资产应急出口。公网版已接入 V3 与 Spark USDC 金库。 |
| 0:20–0:40 | 打开模拟仓位 `28491`，点击读取 | 用户可从总览打开仓位，也可输入编号。此处全部为模拟资产，不是真实钱包余额。 |
| 0:40–1:05 | 选择 50%，预演并打开交易核对 | 展示原协议目标、收款钱包、最低输出和有效期。没有新增托管或代币授权。 |
| 1:05–1:20 | 勾选确认，完成模拟退出，打开操作记录 | 这里只模拟执行与结果；主网公开版保持只读。 |
| 1:20–1:40 | 展示真实金库最终赎回只读核验 | 受限原钱包完成四笔交易，1 USDC 存入后两次共返回 1.000002 USDC，份额归零，全部最终确认。此画面不发送交易。 |
| 1:40–2:10 | 打开恢复入口，显示 TapeOut 名称、历史版本、容器及两个网关 | TapeOut 保存应用文件，TapeExit 处理退出流程。两个网关读取同一容器；本地包提供第三条运行路径，仍需 RPC 与可用的链。 |
| 2:10–2:35 | 展示新版发行与主网关阻断后的金库恢复 | `f8771a8` 完成 16 个文件回读，四个视图 64 次检查；导入恢复文件、刷新并重新核验成功。 |
| 2:35–2:50 | 目标用户、服务方向和规划模块 | 基础工具免费；探索适配、演练、维护服务。生产签名关闭，独立审阅尚未完成。 |

上表是讲解顺序参考。实际成片由 `tools/render-competition-video.mjs` 根据旁白音长排定，
总时长必须由 ffprobe 校验不超过 180 秒。片中没有新增交易或模拟成真实签名的画面。

录制时不要将 Demo 与真实网关画面拼接成一笔真实交易。真实访问与恢复演练应记录完整版本、清单摘要、网络阻断范围、资源来源和交易哈希。

UI 中的“RPC 分歧”只证明模拟行为；公网故障报告才记录具体网络阻断。两个网关不等于链、RPC 或协议故障都能恢复。
不得宣称已覆盖全部 DEX、已审计、永久可用、已有用户或保证获奖。
