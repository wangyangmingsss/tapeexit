# TapeExit 演示脚本

视频不超过 3 分钟，使用中文合成旁白并明确标记场景。
模拟操作取自[在线 Demo](https://wangyangmingsss.github.io/tapeexit/)对应源码的 CI 录像，
真实结果取自固定版本公网验收截图与链上报告；视频元数据分别记录两个源码提交。
精确时长和逐场旁白见交付包 `video.json`，不能将画面理解为钱包签名直播。

| 时间 | 画面与操作 | 讲解要点 |
| --- | --- | --- |
| 0:00–0:19 | 已发布公网界面与产品问题 | TapeOut 承载的 X Layer DeFi 应急出口，当前接入 V3 与 Spark 金库。 |
| 0:19–0:41 | V3 模拟录像 | 读取、选择 50%、预演、核对及模拟退出；明确标记为测试资产。录像源码为 `2597f66`，单独保留记录。 |
| 0:41–1:07 | 真实金库只读核验截图 | 四笔受限交易最终确认；存入 1 USDC，合计返回 1.000002 USDC，份额归零。 |
| 1:07–1:28 | TapeOut 发行与回读 | `f8771a8` 的 16 个文件、647523 字节回读通过；34 笔上传已完成。 |
| 1:28–1:51 | 主网关阻断后的手机恢复 | 四个视图 64 次检查；导入文件、刷新、重新核验与备用入口恢复通过。 |
| 1:51–2:14 | 目标用户、商业假设和下一步 | 开源基础工具与适配、演练、维护服务；生产签名关闭，独立审阅尚未完成。 |

上表是讲解顺序参考。实际成片由 `tools/render-competition-video.mjs` 根据旁白音长排定，
总时长必须由 ffprobe 校验不超过 180 秒。片中没有新增交易或模拟成真实签名的画面。

录制时不要将 Demo 与真实网关画面拼接成一笔真实交易。真实访问与恢复演练应记录完整版本、清单摘要、网络阻断范围、资源来源和交易哈希。

UI 中的“RPC 分歧”只证明模拟行为；公网故障报告才记录具体网络阻断。两个网关不等于链、RPC 或协议故障都能恢复。
不得宣称已覆盖全部 DEX、已审计、永久可用、已有用户或保证获奖。
