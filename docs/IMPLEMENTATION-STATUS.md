# TapeExit 实施状态

本表区分代码、自动化测试与外部验收。生成于 2026-10-27，不能将“已实现”理解为已通过全部原计划验收。

## 已实现且可本地复现

- X Layer 主网只读部署核对；管理器、工厂代码摘要固定。
- 两运营方严格读取、固定区块和重组检查。
- V3 仓位直接所有权、工厂/池/资产身份读取。
- 官方 SDK 精确整数计算；部分/全部退出、单边仓位和仅领取。
- 原管理器组合调用、收款地址绑定、value 为零、独立解码和最低输出重算。
- 发送前账户/链/预览检查、重复发送锁、提交未知时停止。
- 实际交易输入、池 Collect 和 ERC20 转出事件交叉核对。
- pending、revert、重组后的成功撤销、safe/finalized 分离。
- 已知 nonce 消耗时停止并提示检查替换交易；不自动寻找替换哈希。
- 中英文工作区、复核弹窗、焦点管理、本地历史与证据导出。
- 交易哈希即时持久化，刷新后按真实交易重建历史领取证据；失败撤回旧成功状态，清空中的异步复核不复活记录。
- 严格恢复卡导入与可单独运行的本地恢复包。
- 带摘要的发行清单、拒绝混合/额外资源、生产演示分离。
- 固定 TapeKit 源码获取及校验、专用网关构建和保留路径服务器。
- 按文件摘要和分块索引构建的未签名发布计划。
- 发布清单要求干净源提交；额外/缺失文件、符号链接、重复/保留路径和摘要不符均停止；入口与 fallback 最后编码。
- 官方 V3 本地合约集成、DOM、边界与恢复服务测试。
- X Layer 固定区块的实际部署分叉退出、两资产余额增量和剩余流动性核对。
- CI 工作流、许可文本与依赖清单工具。

## 当前明确限制

生产 `RELEASE_APPROVED=false`，`SUPPORTED_TOKENS=[]`。不存在经过批准的主网发送路径。不要通过随意改开关绕过发布门槛。

模拟演示只有测试资产和预设结果。真实原站隔离必须通过网络阻断和请求记录证明，不能用页面状态开关代替。

本机 Playwright 下载完成，但 Chromium 在 macOS 沙箱 MachPortRendezvous 初始化阶段被拒绝，4 项浏览器测试均未进入页面。DOM 测试无法证明布局和像素结果。

GitHub 推送需要用户指定账号的受支持凭证。当前系统已登录账号与用户目标不同，因此未创建远程仓库、未推送。

## 发布顺序

先完成真实浏览器与目标钱包验收、支持资产审阅。随后审阅发布预算、准备真实 TapeOut 容器，逐文件发布回读，部署备用网关，完成原站失联与本地恢复演练。所有外部证据齐全后才能启用生产签名和录制正式参赛演示。
