# TapeExit 实施状态

本表区分代码、自动化测试与外部验收。生成于 2026-10-27，不能将“已实现”理解为已通过全部原计划验收。

## 已实现且可本地复现

- X Layer 主网只读部署核对；管理器、工厂代码摘要固定。
- 两运营方严格读取、固定区块和重组检查。
- 区块号/时间戳 quantity、uint256 长度与 32 字节哈希检查；返回高度必须等于请求高度。新快照拒绝超过 300 秒的旧时间或超前 30 秒的时间，历史验证不套用新快照时间窗口。
- V3 仓位直接所有权、工厂/池/资产身份读取。
- 官方 SDK 精确整数计算；部分/全部退出、单边仓位和仅领取。
- 原管理器组合调用、收款地址绑定、value 为零、独立解码和最低输出重算。
- 发送前账户/链/预览检查、重复发送锁、提交未知时停止。
- 实际交易输入、池 Collect 和 ERC20 转出事件交叉核对。
- pending、revert、重组后的成功撤销、safe/finalized 分离。
- 已知 nonce 消耗时停止并提示检查替换交易；不自动寻找替换哈希。
- 中英文工作区、复核弹窗、焦点管理、本地历史与证据导出。
- 交易哈希即时持久化，刷新后按真实交易重建历史领取证据；失败撤回旧成功状态，清空中的异步复核不复活记录。
- 发送前持久化待处理意图、Web Locks 同源互斥、刷新恢复和独立历史清空；已知哈希核对实际调用及最终性后解除，未知/损坏记录保持阻止发送。新增原生浏览器跨标签页竞争、关闭与取消恢复用例；真实钱包验收仍待完成。
- 恢复完成同步真实结果并清除旧仓位/预览；会话收据高度下限覆盖读取、预演和发送前重查。首次成功后的最终性复核失败会立即撤回成功状态并恢复发送锁。
- 钱包响应丢失后可补入交易哈希；仅匹配原始提交且最终确认才能解锁。格式错误不查询，错误发送者/目标/value/调用不写入，候选输入绑定当前待处理标识。
- 生产入口只接受本地模式或验证成功的 TapeOut 客户端；核对状态与首页身份，预检后重读入口。控制器切换撤回入口/计划，异步钱包检查后再次检查操作代次及控制器；相关测试为协议响应和 DOM 夹具，真实钱包与 SW 验收仍待完成。
- 严格恢复卡导入与可单独运行的本地恢复包。

收据/交易/日志新增严格结构与身份核对：明确二元状态、规范数量与字节、相同区块/哈希/交易索引、日志未移除且索引递增不重复、4096 项上限、回滚无日志；canonical 区块及实际 calldata 核对后才报告回滚。解除待处理锁之前重读完整收据，状态或身份改变保留锁。新增边界和领取/恢复回归，官方 V3 本地合约回滚路径同时覆盖当前收据检查；浏览器夹具结果按当前 CI 解释，不替代真实链重组或扩展钱包验收。

恢复卡导入保留全部最多 50 个唯一规范 uint256 仓位编号，并提供原生下拉选择；有效空卡清除旧线索，错误卡保留已有输入。保存导入集合时保留全部编号，手动选择集合外编号则仅保存当前编号。严格校验可选发行摘要/名称/容器及最多 4 个 HTTPS 网关，禁止导出身份覆盖固定链/管理器/调用字段；导入元数据不授权、不导航、不替换当前运行身份。异步文件读取按导入序号与工作区代次隔离，较晚的旧文件或错误不能覆盖新输入，卸载后失效。新增 50 项 schema/导出边界测试、8 项 DOM 回归和 3 项生产浏览器用例；移动布局和浏览器结果按当前提交 CI 解释。

待处理交易追踪已严格校验交易哈希、发送者、规范 uint256 nonce 及完整待处理/入块索引字段；已知 nonce 不允许被 RPC 改写。账户 nonce 使用固定新鲜区块并复核 canonical 哈希，消耗后重查原交易，仅原交易仍缺失才提示检查替换/取消。原交易已入块但收据延迟时保持待核对。新增 42 项核心边界与竞态测试、5 项生产 UI DOM 锁保持回归；不自动重发或解除持久锁，不代表真实钱包替换/取消验收。

入口状态读取限制为 64 KiB，严格 UTF-8/JSON，身份名称和非零容器格式约束；同一 8 秒期限覆盖状态体和页面头读取，禁止重定向，及时取消不使用的页面响应体。恢复摘要读取限制为 256 KiB，禁止重定向并省略凭据，8 秒期限覆盖响应体；摘要仍只表示取得的原始字节，不独立认证来源或清单内容。生产入口读取失败时不导出缺摘要卡；开发/模拟草稿允许省略摘要。导出按请求序号与工作区代次隔离，迟到结果/错误与卸载后结果失效，成功重试清除错误。新增 28 项入口/摘要边界、3 项实际 loopback HTTP、6 项 DOM 回归和 3 项生产浏览器测试；浏览器结果须核对当前提交 CI，不替代真实 TapeOut/钱包验收。

## 当前明确限制

生产 `RELEASE_APPROVED=false`，`SUPPORTED_TOKENS=[]`。不存在经过批准的主网发送路径。不要通过随意改开关绕过发布门槛。

模拟演示只有测试资产和预设结果。真实原站隔离必须通过网络阻断和请求记录证明，不能用页面状态开关代替。

本机 Chromium 仍在 macOS 沙箱 MachPortRendezvous 初始化阶段被拒绝；此前 16 项已在 GitHub Ubuntu 运行并取得截图。新增用例须检查当前提交的 CI；真实钱包和真实容器不由 DOM/夹具通过结果替代。

公开仓库 `wangyangmingsss/tapeexit` 已创建并上传此前全部提交；每次继续开发后核对远程提交及对应 CI，不复用旧通过结论。

## 发布顺序

先完成真实浏览器与目标钱包验收、支持资产审阅。随后审阅发布预算、准备真实 TapeOut 容器，逐文件发布回读，部署备用网关，完成原站失联与本地恢复演练。所有外部证据齐全后才能启用生产签名和录制正式参赛演示。
